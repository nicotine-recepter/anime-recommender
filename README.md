# 🍿 內帶資料庫之 AI 動漫選片助手 (Anime Recommendation Assistant with In-Context DB)

本專案包含一套結合 **Prompt Engineering（提示工程）** 與 **In-Context Knowledge Base（上下文內建資料庫）** 的 System Prompt，以及對應的互動式網頁系統 (`index.html`)。

---

## 📌 專案亮點與解決痛點

在未經過提示工程設計的情況下，向 LLM 詢問「推薦我好看的動漫」通常面臨以下問題：
1. **幻覺與隨機推薦**：模型容易瞎編無關作品或盲目推薦大眾熱門爆款。
2. **缺乏偏好過濾**：無法根據使用者個人的時間篇幅、情緒氛圍及「避雷元素」進行主動排除。
3. **資訊無法驗證**：模型輸出的特色與叮嚀缺乏標準化的真實資料庫支持。

本專案透過在 Prompt 中**嵌入結構化 Markdown 資料庫 (A01–A10)** 並設定**負向約束與比對邏輯**，成功達成 **100% 精準檢索** 與 **零幻覺推薦**。

## 🎯 提示工程 (Prompt Engineering) 技巧說明

1. **Role Prompting（角色定義）**：設定專屬動漫專家語氣與權威感，提升互動真實度。
2. **In-Context Knowledge Base（上下文知識庫）**：將 10 部作品資料結構化為表格，解決資料庫未涵蓋或資訊不準確之問題。
3. **Negative Constraint（負向條件過濾）**：透過 Q4 與「避雷標籤」欄位比對，自動剔除使用者討厭的元素（如虐心、過慢、血腥）。
4. **Structured Output（固定結構化輸出）**：限制僅輸出 **精準 3 部**，並統一欄位（契合點、亮點、叮嚀），大幅提升閱讀體驗。

## 🌐 網頁端 `index.html` 應用說明

系統已同步生成互動式 Web 應用程式，功能包含：
- **互動問卷區**：視覺化點選 Q1–Q4 選項。
- **即時比對引擎**：前端演算法與內建 DB 比對，即時顯示最適 3 部作品卡片。
- **資料庫瀏覽器**：可一鍵切換查看完整的 10 部作品詳細標籤與屬性。
